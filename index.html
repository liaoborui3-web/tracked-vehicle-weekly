Update Guide

后续怎么更新

1. 修改周报内容

打开 js/data.js，按照示例新增一周，填写标题、日期、目标、完成内容、问题、计划和标签。

2. 放入图片和视频

把图片或视频复制到 media/week04/ 这样的文件夹里，再在 media 字段中写对应路径。

3. 打开展示

直接双击 index.html 即可本地查看，也可以上传到 GitHub Pages、学校服务器或任意静态网站空间。
